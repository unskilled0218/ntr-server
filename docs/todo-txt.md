# todo.txt support

Tasks use the plain [todo.txt](https://github.com/todotxt/todo.txt) format as their canonical store.

Priorities `(A)`–`(Z)`, completion (`x`), completion/creation dates, `+projects`, `@contexts`, and `key:value` tags. When a task is completed its priority is preserved as a `pri:X` tag and restored on un-completion.
