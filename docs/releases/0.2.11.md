# Release v0.2.11

- [Changes](#changes)

## Changes

- Load optional `.env` settings from the server's exact working directory without changing the process environment or searching parent directories. Existing process values, including empty values, take precedence.
- Fail startup on malformed/unreadable dotenv files with sanitized errors, before opening resource stores.
- Add a tracked `.env.example`, private-file Git exclusions, and an opt-in Compose override that injects the file and mounts token/certificate directories read-only.
- Keep protected token-file authentication, certificate verification, file-backed defaults, Markdown notes, and the base Compose deployment unchanged. Prepared locally, not published.
