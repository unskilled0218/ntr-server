# Release v0.2.14

- [Changes](#changes)
- [Compatibility](#compatibility)

## Changes

- Update tower-http to 0.7, reqwest to 0.13, tokio-tungstenite to 0.30, and compatible locked Rust dependencies.
- Select one explicit ring-based Rustls configuration with shared web-PKI/custom CA roots for HA HTTPS and WSS. Preserve hostname checks, rejected redirects, operation/message bounds, origin filtering, and durable no-replay recovery.

## Compatibility

Task APIs, metadata schema, `.env` configuration, file-backed tasks/notes, and Unix sidecar durability requirements are unchanged. Validation uses Rust 1.100.0 and disposable generated-CA fixtures, not live HA. This local preparation does not publish images or deploy the server. See [dependency checks](../development.md#dependency-updates).
