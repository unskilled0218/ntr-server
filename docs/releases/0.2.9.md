# Release v0.2.9

- [Release v0.2.9](#release-v029)

Adds optional `X-Ntr-Client-Id` origin metadata for task, raw-task, and note mutations and SSE subscriptions. Matching subscribers omit their own successful mutations; watcher and foreign changes still notify. Legacy subscribers retain the existing event format and delivery.

Broadcast overflow now sends both existing `tasks` and `note` rescan tokens before retained events, bypassing origin filtering. Legacy clients may automatically refresh both resources on lag; updated client `0.15.19` detects content and requests approval instead.

The header is not authentication. Storage remains last-write-wins with no revision history or transactional compare-and-swap. Prepared locally, not published.
