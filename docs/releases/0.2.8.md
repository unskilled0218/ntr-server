# Release v0.2.8

- [Release v0.2.8](#release-v028)

Removes active priority semantics, the task DTO priority field, and priority filtering. Any HTTP priority query now returns a clear 400, including empty, invalid, and repeated values. Supported filters retain their validation.

Preserves existing hidden leading `(A)`–`(Z)` tokens before lifecycle dates across edits, completion, reopening, and unrelated writes. `pri:` tokens remain ordinary description text; lifecycle actions no longer convert them. Reading does not migrate task files.

Pair with client `0.15.18` for the full preservation guarantee. Older clients are unsupported for priority-dependent behavior. A new client can preserve legacy data on edits against an older server using validated raw text, but older-server completion and reopening can still convert it. See [todo.txt compatibility](../todo-txt.md).

Prepared locally, not published. Release tooling and container configuration are otherwise unchanged.
