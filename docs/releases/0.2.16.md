# Release v0.2.16

- [Changes](#changes)
- [Compatibility](#compatibility)

## Changes

Use List terminology in task/label domain fields, filters, tests, and maintained documentation.

## Compatibility

Existing task-response `projects`, remembered-label `project`, and legacy query `project` keys remain compatible. The `list` query spelling is also accepted. Task text, stored labels, HA identities, and move recovery behavior are unchanged. No image publication or deployment is implied.
