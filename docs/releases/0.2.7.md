# Release v0.2.7

- [Release v0.2.7](#release-v027)

The server release tools now support package association on reviewed stable Gitea 28.2.0 alongside stable Gitea 1.25.x, retaining conflict refusal and single-write readback verification.

Explicit pinned recovery can finish association for an existing verified publication without rebuilding, republishing, or executing historical scripts. Phase messages and bounded waiting updates show progress without relaying credentials or raw tool output. Application behavior and runtime configuration remain unchanged.
