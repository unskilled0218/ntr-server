# Release v0.2.5

- [Release v0.2.5](#release-v025)

The server's container release workflow now uses strict project settings, private token-file credentials, verified AMD64/ARM64 image digests, and committed project release notes. A canonical version file is checked against Rust metadata.

Publication binds source and image identity in annotated Git tags, promotes the verified image to `latest`, and verifies repository package association on supported servers. Unsafe post-promotion alias changes and isolated-auth Buildx selection changes stop publication.

The Rust server's API, non-root execution, persistent data paths, and configuration remain unchanged. New image releases no longer create versioned image aliases or upload image archive attachments; historical artifacts remain unchanged.
