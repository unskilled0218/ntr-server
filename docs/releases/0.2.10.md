# Release v0.2.10

- [Changes](#changes)
- [Compatibility](#compatibility)

## Changes

- Add a server-side Home Assistant To-do backend for one configured list, with verified HTTPS, optional private-CA trust, and token-file authentication.
- Persist numeric UID mappings and ntr lifecycle metadata independently of HA task data. Preserve HA descriptions and native date/datetime due values.
- Poll full item snapshots and send safe origin-aware task notifications, including unfiltered rescans for concurrent external changes and uncertain writes.
- Expose backend capabilities and reject whole-file task replacement in HA mode. Keep notes, labels, local files, and the default file backend unchanged.

## Compatibility

Use client 0.15.31 or later for HA-safe reconnect reconciliation. Existing task files are not migrated. Back up the HA metadata sidecar. Review [configuration, lifecycle limits, and container setup](../home-assistant.md) before selecting a production list. Prepared locally, not published.
