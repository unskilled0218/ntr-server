# Release v0.2.6

- [Release v0.2.6](#release-v026)

The server release publisher now explicitly disables Git follow-tags for its release-tag push. An enabled `push.followTags` preference no longer publishes unrelated local annotated tags, and the user's Git configuration remains unchanged.

Regression coverage checks actual remote refs for ordinary publication, accepted-but-lost tag responses, and read-only completed retries. Non-force publication and exact release identity verification remain unchanged.
